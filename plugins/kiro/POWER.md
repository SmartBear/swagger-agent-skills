# SmartBear Swagger

Design, validate, and publish APIs directly from Kiro using SmartBear's hosted Swagger MCP server.

## Prerequisites

- A SmartBear account (free tier available at [swagger.io](https://swagger.io/tools/swaggerhub/))
- Internet access to `swagger.mcp.smartbear.com`

## Getting Started

On first use, Kiro will open a browser window for SmartBear OAuth login. No API tokens or manual configuration required.

## What You Can Do

- **Search and browse** your Swagger organization's APIs and domains
- **Fetch API definitions** from the registry (OpenAPI 2.0, 3.0, 3.1)
- **Create or update APIs** in Swagger Studio
- **Validate governance** — scan definitions against your organization's standardization rules
- **AI-assisted design** — generate an API definition from a natural-language description
- **Auto-fix violations** — apply governance fixes automatically
- **Manage portals** — create documentation pages, publish API portal products
